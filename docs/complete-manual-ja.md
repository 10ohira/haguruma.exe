## 1. そもそも何をするソフトか

PCの中に **偽のスマホ（BlueStacks）** を立ち上げ、その中でゲーム（ミルクチョコ）を動かします。
このソフト（はぐるま）はそのゲームに「くっついて」動きます。

くっつく流れは **橋を順番に4本渡る**ようなもの。画面にもこの4行が出ます：

```
 ① ADB   →   ② サーバ   →   ③ Frida   →   ④ セッション
 (電話をかける) (道具を入れる) (道具に接続)   (ゲームにくっつく)
```

- 4行すべて **緑ランプ** になれば成功 🎉
- どれかが **赤ランプ** なら、その段階で詰まっています → 5番の辞典で探します。

> 💡 **99%は `ワンクリック接続` ボタン1つで ①②③ が自動で終わります。**
> なので2番のインストールさえ正しくやれば、普段はボタン1回でOKです。

## 2. 最初の1回だけのインストール（最重要）

> ⚠️ この5つは **1つでも抜けると絶対つながりません。** ゆっくり全部やってください。

### ✅ 2-1. BlueStacks をインストール
1. ネットで **`BlueStacks 5`** を検索 → 公式サイト（bluestacks.com）からダウンロード
2. インストールして起動

### ✅ 2-2. BlueStacks で「ADB」をオンにする ⭐⭐⭐（一番よく忘れる）
1. BlueStacks 画面 **右下の歯車（⚙️ 設定）** をクリック
2. 左の一覧から **`詳細設定`（Advanced）** をクリック
3. **`Android デバッグブリッジ（ADB）`** のスイッチを **オン（ON）** にする
4. オンにすると下にアドレスが出ます。たいてい **`127.0.0.1:5555`** → 覚えておく。

### ✅ 2-3. BlueStacks で「ルート（Root）」をオンにする ⭐⭐⭐
道具を入れるには管理者権限（ルート）が必要です。
1. 同じ **`詳細設定`（Advanced）** 画面で
2. **`ルートアクセス`（Root access）** を **オン（ON）**
3. ⚠️ **設定を変えたら BlueStacks を完全に閉じて開き直す。**（再起動しないと反映されません）

### ✅ 2-4. ゲーム（ミルクチョコ）をインストール
1. BlueStacks 内の **Play ストア** を開く
2. **`MilkChoco`（ミルクチョコ）** を検索 → インストール

### ✅ 2-5. ウイルス対策（Windows セキュリティ）の除外登録 ⭐⭐（やらないとソフトが消えます）
このソフトはゲームにくっつく道具なので、ウイルス対策が **「悪いソフト」と勘違いして勝手に削除** することがあります。
1. スタートメニューで **`Windows セキュリティ`** を検索 → 起動
2. **`ウイルスと脅威の防止`** をクリック
3. **`設定の管理`** → 下にスクロールして **`除外` → `除外の追加`**
4. **`フォルダー`** を選択 → **はぐるま がインストールされたフォルダー** を丸ごと追加
5. （ゲーム道具を別フォルダーに入れた場合はそれも追加）

> 💬 見分け方：入れたソフトが数日後に消えていたり、「サーバ」段階で何度も失敗するなら、
> ほぼ確実にウイルス対策が消しています。→ 上の除外登録のあと再インストール。

### ✅ 2-6. はぐるま（このソフト）をインストール
1. 受け取ったインストーラ（`はぐるま-Setup-….exe`）をダブルクリック
2. インストール後に起動 → **ID とパスワードでログイン**（権限がなければログイン画面の `Request access` から申請）

> 🎁 ゲームにくっつく道具（frida-server）は **ソフトに最初から入っています。**
> 別途ダウンロード不要、自動で入ります。

## 3. 毎回ゲーム前にやる接続手順

> 順番が大事。**BlueStacks が先 → ゲーム → ソフト → ボタン** の順を守ってください。

1. 🟦 **BlueStacks を起動。**
2. 🥛 BlueStacks 内で **ミルクチョコを起動**。（ロビー画面まで入ると一番安全）
3. ⚙️ **はぐるま** を起動してログイン。
4. 左メニューの **`Initialize`（初期化）** をクリック。
5. 一番上の **`ワンクリック接続`** ボタンをクリック 👈 **これ1つでOK**
6. **ADB → サーバ → Frida** の行が順に **緑ランプ** になるのを見守る。

### ゲーム機能をオンにする（Frida が緑になったあと）
7. **`Get Cookie`（クッキー取得）** をクリック → クッキー欄が埋まる
8. **`Start Agent`（エージェント起動）** をクリック → **セッション** が緑になれば完了 🎉

> 📌 シリアル（serial）欄は初期値 `127.0.0.1:5555` のままに。
> BlueStacks を複数起動した／アドレスが違う場合は、2-2 で見たアドレスに変更。

## 4. 画面の文字・ボタンの意味

### 状態の行（ランプで状態を表示）
| 行 | どの段階？ | 緑なら？ |
|---|---|---|
| **ADB** | PC ↔ エミュレータの電話接続 | エミュレータを発見 |
| **サーバ（Server）** | エミュレータに道具を入れて起動 | 道具が動いている |
| **Frida** | PC がその道具に接続 | 接続成功 |
| **セッション（Session）** | 実際にゲームへくっつく | 機能を使う準備OK |

ランプの色：🟡 黄＝進行中 / 🟢 緑＝成功 / 🔴 赤＝失敗

### ボタン
| ボタン | 役割 | 普段使う？ |
|---|---|---|
| **ワンクリック接続** | ADB＋サーバ＋Frida を順番に自動で | ⭐ いつもこれだけ |
| Connect ADB | ADB だけ接続 | 詰まった段階を個別に見るとき |
| Connect Serial | （Wi-Fi方式の）ADB 接続 | ほぼ使わない |
| Start Server | サーバだけ起動 | 〃 |
| Connect Frida | Frida だけ接続 | 〃 |
| Download / Upload Server | 道具を手動で取得/投入 | 特殊なときだけ（通常不要） |
| Get Cookie | ゲームのクッキー取得 | 接続後に1回 |
| Start Agent | ゲームに機能をくっつける | 接続後に1回 |

## 5. 🚨 エラーメッセージ辞典（全部）

画面に出た **赤い文字をそのまま** 下から探してください。（英語で出ます）

### 🔑 ログイン時
ログインは **ID＋パスワード** です。（初回はログイン画面の **`Request access`** からアクセス申請してください。）

| 画面の文字 | 意味 | 対処 |
|---|---|---|
| ID / Password | ID かパスワード欄が空 | 両方を入力してください。 |
| Login failed | ログイン失敗 | ID/パスワードが違う、または権限なし。正確に再入力。 |
| HTTP 401 / 403 | 認証拒否 | アカウント未承認/権限なし。`Request access` で申請するか管理者へ。 |
| HTTP 500 など（HTTP＋数字） | サーバエラー | こちらのサーバの問題。少し待って再試行。 |
| network error | ネット未接続 | ネット確認、Wi-Fi入れ直し、少し待って再試行。 |
| Login error | 不明なログインエラー | ソフトを再起動して再試行。続くなら再インストール。 |

### 🟦 ① ADB の行が赤
| メッセージ | 意味 | 対処 |
|---|---|---|
| No emulator found. Enable ADB in BlueStacks... | エミュレータが見つからない | **2-2（ADBをオン）** をしたか確認。BlueStacks が起動中か確認。 |
| Failed to connect to adb | ADB 接続失敗 | BlueStacks を **再起動** して再試行。アドレス（`127.0.0.1:5555`）確認。 |
| Failed to get ip address | IP が取れない | （Wi-Fi方式のときのみ）初期シリアルのまま **`ワンクリック接続`** を使う。 |

### 🟩 ② サーバ（Server）の行が赤
| メッセージ | 意味 | 対処 |
|---|---|---|
| ADB not connected | ADB が先に済んでいない | まず① ADB。`ワンクリック接続` を再度押す。 |
| Failed to get arch | 端末種別の判定失敗 | BlueStacks 再起動後に再試行。 |
| Cannot find frida server | 同梱の道具ファイルがない | **ウイルス対策が消した可能性大** → 除外登録（2-5）後に **再インストール**。 |
| Failed to deploy frida server | 道具をエミュに入れられない | エミュの空き容量を確保、BlueStacks 再起動、再試行。 |
| Frida permissions denied | 権限拒否 | **ルート（2-3）がオフ。** オンにして **BlueStacks 再起動**。 |
| Frida server crashed | 道具が落ちた | BlueStacks 再起動 → 最初からやり直し。 |
| Failed to start frida server | 道具の起動失敗 | 上のルート確認＋BlueStacks 再起動。 |

### 🟪 ③ Frida の行が赤
| メッセージ | 意味 | 対処 |
|---|---|---|
| ADB not connected | ADB が先に済んでいない | `ワンクリック接続` を再度。 |
| Failed to connect to frida server | 道具に接続できない | サーバが起動直後かも。**5秒待って `Connect Frida` を再度。**（`ワンクリック接続` は自動で再試行します） |
| Frida server crashed | 道具が途中で落ちた | BlueStacks 再起動 → 最初から。 |

### 🟧 ④ セッション（Session）の行が赤
| メッセージ | 意味 | 対処 |
|---|---|---|
| Frida not connected | Frida が先に済んでいない | ③ Frida を緑にしてから押す。 |
| Failed to get cookie | クッキーが取れない | **ゲームが起動中（ロビー）** か確認して再試行。 |
| Failed to start agent | 機能をくっつけられない | 先に `Get Cookie` → 次に `Start Agent`。ダメならゲーム再起動。ゲーム/ソフトのバージョンが合わなければ両方を最新に更新。 |
| Session disposed | ゲームとの接続が切れた | ゲームが落ちた/閉じた。ゲームを再起動して最初から。 |

## 😱 どうしても分からなければまずこれ（万能リセット）

**どんなエラーでも約90%はこの順でなおります。上から順に。**

1. 🥛 **ミルクチョコを完全に終了**
2. 🟦 **BlueStacks を完全に終了**（タスクバー/トレイからも）
3. ⚙️ **はぐるま も終了**
4. 🟦 **BlueStacks を開き直す**
5. 🔍 BlueStacks 設定 → 詳細設定で **ADBオン / ルートオン** を再確認（2-2, 2-3）
6. 🥛 **ミルクチョコ起動 → ロビーまで入る**
7. ⚙️ **はぐるま 起動 → ログイン → Initialize → `ワンクリック接続`**
8. それでもダメなら：
   - PC を一度 **再起動**
   - **ウイルス対策の除外（2-5）** を再確認 ＋ ソフトを **再インストール**
   - ソフトとゲームを **最新版** に更新

## 7. よくある質問

**Q. ファイアウォールを下げる必要ある？**
A. ❌ いいえ。Frida 接続はすべてPC内（localhost）で起きるのでファイアウォールは無関係です。
   本当の原因はたいてい **ウイルス対策（2-5）**。ファイアウォールの許可ダイアログは「モバイルコントローラ」機能を使うときだけ出るので、そのときは **［許可］** を押すだけ。

**Q. `ワンクリック接続` と下のボタンの違いは？**
A. `ワンクリック接続` は下のボタンを **自動で順番に** 押すものです。普段はこれだけでOK。

**Q. frida-server は毎回ダウンロードが必要？**
A. ❌ いいえ。同梱されていて自動で入ります。Download/Upload ボタンは上級者向けで触る必要はありません。

**Q. 一度つなげば接続は続く？**
A. ゲームや BlueStacks を閉じると切れます。次回また **`ワンクリック接続`** を押すだけ。

**Q. ソフトが何度も消える。**
A. ウイルス対策が削除しています。必ず **除外登録（2-5）** をしてください。
