# はぐるま 연결 가이드 (완전 초보용)

이 문서는 **컴퓨터/코딩을 전혀 몰라도** 따라 할 수 있도록 쓴 연결 설명서입니다.
순서대로만 따라 하면 됩니다.

---

## 0. 먼저 알아두기 (개념 1분 정리)

이 프로그램은 **PC에서 돌아가는 안드로이드 에뮬레이터(블루스택) 안의 게임**에
붙어서 동작합니다. 붙는 과정은 다리를 4개 건너는 것과 같습니다.

```
  PC(はぐるま)  →  ① ADB  →  ② 서버  →  ③ 프리다  →  ④ 세션
                 (전화 연결)  (도구 설치)  (도구 접속)  (게임 후킹)
```

- **① ADB** : PC가 에뮬레이터와 "전화 연결"을 하는 단계
- **② 서버** : 에뮬레이터 안에 도구(frida-server)를 깔고 켜는 단계
- **③ 프리다** : PC가 그 도구에 실제로 "접속"하는 단계
- **④ 세션** : 게임에 붙어서 기능을 쓰는 단계

화면의 ADB / 서버 / 프리다 / 세션 4줄이 **전부 초록불(연결됨)** 이 되면 성공입니다.

> **가장 중요한 한 줄:** 대부분의 경우 **`한 번에 연결` 버튼 하나만 누르면** ①②③이
> 자동으로 진행됩니다. 아래 "1. 처음 한 번만 하는 설치 세팅"만 끝내두면 됩니다.

---

## 1. 처음 한 번만 하는 설치 세팅

이건 **딱 한 번만** 해두면 됩니다. (다음부터는 안 해도 됨)

### 1-1. 블루스택(BlueStacks 5) 설치
1. [https://www.bluestacks.com](https://www.bluestacks.com) 에서 **BlueStacks 5** 를 받아 설치합니다.
2. 설치가 끝나면 블루스택을 실행합니다.

### 1-2. 블루스택에서 ADB 켜기 ⭐ (이걸 안 하면 절대 연결 안 됩니다)
1. 블루스택 오른쪽 아래 **톱니바퀴(설정)** 클릭
2. **고급(Advanced)** 메뉴로 이동
3. **Android 디버그 브리지(ADB)** 항목을 **켜기(ON)** 로 변경
4. (포트 번호가 보이면 적어두세요. 보통 `127.0.0.1:5555` 입니다.)

### 1-3. 블루스택에서 루트(Root) 켜기 ⭐
서버를 켜려면 관리자 권한(루트)이 필요합니다.
1. 설정 → **고급(Advanced)**
2. **루트 액세스(Root access)** 를 **켜기(ON)**
3. 설정을 바꾼 뒤에는 블루스택을 **한 번 재시작**합니다.

### 1-4. 게임(밀크초코) 설치
1. 블루스택 안의 **Play 스토어**에서 **MilkChoco(밀크초코)** 를 설치합니다.

### 1-5. はぐるま(이 프로그램) 설치
1. 받은 설치 파일(`はぐるま-Setup-x.xx.x.exe`)을 더블클릭해 설치합니다.
2. 설치가 끝나면 프로그램을 실행하고 로그인 키를 입력합니다.

> frida-server(②에서 깔리는 도구)는 **프로그램에 이미 들어 있어서** 따로
> 다운로드할 필요가 없습니다. 자동으로 에뮬레이터에 설치됩니다.

---

## 2. 매번 게임할 때 하는 연결 (이게 핵심)

### 2-1. 순서
1. **블루스택을 먼저 켭니다.**
2. 블루스택 안에서 **밀크초코 게임을 실행**합니다. (로비 화면까지 들어가면 가장 안전)
3. **はぐるま 프로그램**을 켜고 로그인합니다.
4. 왼쪽 메뉴에서 **`Initialize`(초기화)** 를 클릭합니다.
5. 맨 위 **`한 번에 연결`** 버튼을 누릅니다.
6. ADB → 서버 → 프리다 줄이 차례로 **초록불**이 되는지 지켜봅니다.

이게 끝입니다. 보통 여기까지면 연결 완료입니다.

### 2-2. 게임 기능 켜기 (세션)
프리다까지 초록불이 되면:
1. **`Get Cookie`(쿠키 가져오기)** 버튼을 누릅니다. → 쿠키 칸이 채워집니다.
2. **`Start Agent`(에이전트 시작)** 버튼을 누릅니다. → 세션이 초록불이 되면 기능 사용 준비 끝.

> 시리얼(serial) 칸은 기본값 `127.0.0.1:5555` 그대로 두면 대부분 잘 됩니다.
> 블루스택을 여러 개 켰거나 포트가 다르면, 1-2에서 적어둔 포트로 바꿔주세요.

## 3. 안 될 때 (오류 메시지별 해결법)

화면 각 줄 옆의 빨간 글씨(로그)를 보고 아래에서 찾으세요.

### ADB 줄이 빨간불일 때
| 메시지 | 뜻과 해결 |
|---|---|
| `No emulator found. Enable ADB in BlueStacks...` | 에뮬레이터를 못 찾음. **블루스택이 켜져 있는지**, **1-2 ADB 켜기**를 했는지 확인하세요. |
| `Failed to connect to adb` | 연결 실패. 블루스택을 **재시작**하고 다시 시도하세요. 시리얼 포트 번호가 맞는지도 확인. |
| `Failed to get ip address` | (Wi-Fi 연결 모드일 때) 시리얼/포트가 틀렸습니다. 기본값 `127.0.0.1:5555` 로 두고 `한 번에 연결`을 쓰세요. |

### 서버 줄이 빨간불일 때
| 메시지 | 뜻과 해결 |
|---|---|
| `Frida permissions denied` | **루트(Root)** 권한 문제. **1-3 루트 켜기**를 하고 블루스택을 재시작하세요. |
| `Cannot find frida server` | 내장 서버 파일을 못 찾음. 프로그램을 **재설치**하면 보통 해결됩니다. |
| `Failed to deploy frida server` | 에뮬레이터에 파일 복사 실패. 에뮬 저장공간이 충분한지 확인하고 재시도. |
| `Frida server crashed` | 서버가 꺼짐. 블루스택을 재시작한 뒤 다시 `한 번에 연결`. |

### 프리다 줄이 빨간불일 때
| 메시지 | 뜻과 해결 |
|---|---|
| `ADB not connected` | 먼저 ADB부터 연결되어야 합니다. `한 번에 연결`을 다시 누르세요. |
| `Failed to connect to frida server` | 서버가 아직 안 떠서 그럴 수 있습니다. **5초쯤 기다렸다가** `Connect Frida`를 다시 눌러보세요. (`한 번에 연결`은 내부적으로 자동 재시도합니다.) |
| `Frida server crashed` | 서버가 도중에 꺼짐. 블루스택 재시작 후 처음부터 다시. |

### 그래도 안 되면 (만능 해결 순서)
1. **밀크초코 게임 종료**
2. **블루스택 완전 종료 후 재시작**
3. 블루스택에서 **ADB / 루트가 켜져 있는지** 다시 확인
4. **밀크초코 실행 → 로비 진입**
5. はぐるま에서 **`한 번에 연결`** 다시 클릭

## 4. 자주 묻는 질문

**Q. `한 번에 연결`이랑 아래 버튼들(Connect ADB, Start Server...)은 뭐가 달라요?**
A. `한 번에 연결`은 그 버튼들을 **자동으로 순서대로 눌러주는** 것입니다.
   문제가 생긴 단계만 따로 확인하고 싶을 때 아래 버튼들을 하나씩 써도 됩니다.

**Q. 매번 frida-server를 다운로드해야 하나요?**
A. 아니요. 프로그램에 들어 있고 자동으로 설치됩니다.
   `Download Server` / `Upload Server` 버튼은 특수한 경우에만 쓰는 고급 기능입니다.

**Q. 한 번 연결했는데 게임을 다시 켜면 또 해야 하나요?**
A. 네. 게임이나 에뮬레이터를 재시작하면 `한 번에 연결`을 다시 눌러주세요.
