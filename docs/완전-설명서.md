## 1. 이게 뭐 하는 프로그램인지

PC 안에 **가짜 휴대폰(블루스택)** 을 띄우고, 그 안에서 게임(밀크초코)을 돌립니다.
이 프로그램(はぐるま)은 그 게임에 "붙어서" 동작합니다.

붙는 과정은 **다리 4개를 순서대로 건너는 것**과 같아요. 화면에도 이 4줄이 보입니다:

```
 ① ADB   →   ② 서버   →   ③ 프리다   →   ④ 세션
 (전화걸기)   (도구설치)   (도구접속)    (게임에 붙기)
```

- 4줄이 **전부 초록불**이 되면 성공 🎉
- 어느 줄이 **빨간불**이면, 그 줄이 막힌 겁니다 → 5번 사전에서 찾으면 됩니다.

> 💡 **99%는 `한 번에 연결` 버튼 하나로 ①②③이 자동으로 끝납니다.**
> 그러니 2번 설치만 제대로 해두면 평소엔 버튼 한 번이면 돼요.

## 2. 딱 한 번만 하는 설치 (제일 중요)

> ⚠️ 여기 5개 중 **하나라도 빼먹으면 절대 연결 안 됩니다.** 천천히 다 하세요.

### ✅ 2-1. 블루스택 설치
1. 인터넷에서 **`BlueStacks 5`** 검색 → 공식 사이트(bluestacks.com)에서 다운로드
2. 설치하고 실행

### ✅ 2-2. 블루스택에서 "ADB" 켜기 ⭐⭐⭐ (제일 자주 빼먹음)
1. 블루스택 화면 **오른쪽 아래 톱니바퀴(⚙️ 설정)** 클릭
2. 왼쪽 목록에서 **`고급` (Advanced)** 클릭
3. **`Android 디버그 브리지(ADB)`** 스위치를 **켜기(ON)**
4. 켜면 아래에 주소가 뜹니다. 보통 **`127.0.0.1:5555`** → 이거 그대로 외워두세요.

### ✅ 2-3. 블루스택에서 "루트(Root)" 켜기 ⭐⭐⭐
도구를 설치하려면 관리자 권한이 필요합니다.
1. 같은 **`고급` (Advanced)** 화면에서
2. **`루트 액세스` (Root access)** 를 **켜기(ON)**
3. ⚠️ **설정을 바꿨으면 블루스택을 완전히 껐다 켜세요.** (재시작 안 하면 적용 안 됨)

### ✅ 2-4. 게임(밀크초코) 설치
1. 블루스택 안의 **Play 스토어** 실행
2. **`MilkChoco`(밀크초코)** 검색 → 설치

### ✅ 2-5. 백신(Windows 보안) 예외 등록 ⭐⭐ (이거 안 하면 프로그램이 사라져요)
이 프로그램은 게임에 붙는 도구라서, 백신이 **"나쁜 프로그램"으로 오해하고 멋대로 삭제**할 수 있습니다.
1. 시작 메뉴에서 **`Windows 보안`** 검색 → 실행
2. **`바이러스 및 위협 방지`** 클릭
3. **`설정 관리`** → 아래로 내려서 **`제외 항목` → `제외 추가`**
4. **`폴더`** 선택 → **はぐるま 가 설치된 폴더**를 통째로 추가
5. (게임 도구를 다운로드한 폴더가 따로 있으면 그것도 추가)

> 💬 증상으로 알아채기: 설치한 프로그램이 며칠 뒤 사라져 있거나, "서버" 단계에서
> 자꾸 실패하면 십중팔구 백신이 지운 겁니다. → 위 예외 등록 후 재설치.

### ✅ 2-6. はぐるま 프로그램 설치
1. 받은 설치 파일(`はぐるま-Setup-….exe`)을 더블클릭
2. 설치 끝나면 실행 → 로그인 키 입력

> 🎁 게임에 붙는 도구(frida-server)는 **프로그램 안에 이미 들어 있습니다.**
> 따로 다운로드 안 해도 자동으로 설치돼요.

## 3. 매번 게임할 때 연결하는 법

> 순서가 중요합니다. **블루스택 먼저 → 게임 → 프로그램 → 버튼** 순서를 지키세요.

1. 🟦 **블루스택을 켭니다.**
2. 🥛 블루스택 안에서 **밀크초코를 실행**합니다. (로비 화면까지 들어가면 제일 안전)
3. ⚙️ **はぐるま 프로그램**을 켜고 로그인합니다.
4. 왼쪽 메뉴 **`Initialize`(초기화)** 클릭
5. 맨 위 **`한 번에 연결`** 버튼 클릭 👈 **이거 하나면 끝**
6. **ADB → 서버 → 프리다** 줄이 차례로 **초록불**이 되는지 봅니다.

### 게임 기능 켜기 (프리다 초록불이 된 뒤)
7. **`Get Cookie`(쿠키 가져오기)** 클릭 → 쿠키 칸이 채워짐
8. **`Start Agent`(에이전트 시작)** 클릭 → **세션**이 초록불 되면 완료 🎉

> 📌 시리얼(serial) 칸은 기본값 `127.0.0.1:5555` 그대로 두세요.
> 블루스택을 여러 개 켰거나 주소가 다르면 2-2에서 본 주소로 바꿔주세요.

## 4. 화면에 있는 글자/버튼이 뭔지

### 상태 줄 (불빛으로 상태를 보여줌)
| 줄 이름 | 무슨 단계? | 초록불이면? |
|---|---|---|
| **ADB** | PC ↔ 에뮬레이터 전화 연결 | 에뮬레이터를 찾았다 |
| **서버(Server)** | 에뮬레이터에 도구 설치+실행 | 도구가 켜졌다 |
| **프리다(Frida)** | PC가 그 도구에 접속 | 접속 성공 |
| **세션(Session)** | 게임에 실제로 붙음 | 기능 사용 준비 끝 |

불빛 색 뜻: 🟡 노란불 = 진행 중 / 🟢 초록불 = 성공 / 🔴 빨간불 = 실패

### 버튼
| 버튼 | 하는 일 | 평소에 써요? |
|---|---|---|
| **한 번에 연결** | ADB+서버+프리다를 자동으로 순서대로 | ⭐ 항상 이것만 |
| Connect ADB | ADB만 따로 연결 | 문제 생긴 단계만 따로 볼 때 |
| Connect Serial | (Wi-Fi 방식) ADB 연결 | 거의 안 씀 |
| Start Server | 서버만 따로 시작 | 〃 |
| Connect Frida | 프리다만 따로 연결 | 〃 |
| Download / Upload Server | 도구 직접 받기/넣기 | 특수한 경우만 (보통 불필요) |
| Get Cookie | 게임 쿠키 가져오기 | 연결 후 1번 |
| Start Agent | 게임에 기능 붙이기 | 연결 후 1번 |

## 5. 🚨 오류 메시지 사전 (전부 다)

화면에 뜬 **빨간 글씨를 그대로** 아래에서 찾으세요. (영어로 떠요)

### 🔑 로그인할 때
| 메시지 | 한국어 뜻 | 해결법 |
|---|---|---|
| Please enter your key | 키를 입력해주세요 | 키 칸이 비었어요. 키를 붙여넣으세요. |
| Invalid key | 유효하지 않은 키 | 키를 잘못 입력함. 공백 없이 정확히 복붙하세요. |
| Key expired | 키가 만료됨 | 키 기간이 끝남. 새 키를 받아야 합니다. |
| Network error / Cannot connect to server | 네트워크/서버 연결 안 됨 | 인터넷 확인. 와이파이 껐다 켜기. 잠시 뒤 재시도. |
| Server error | 서버 오류 | 우리 쪽 서버 문제. 잠시 후 다시 시도하세요. |

### 🟦 ① ADB 줄이 빨간불
| 메시지 | 뜻 | 해결법 |
|---|---|---|
| No emulator found. Enable ADB in BlueStacks... | 에뮬레이터 못 찾음 | **2-2 ADB 켜기**를 했는지 확인. 블루스택이 켜져 있는지 확인. |
| Failed to connect to adb | ADB 연결 실패 | 블루스택 **재시작** 후 다시. 주소(`127.0.0.1:5555`) 확인. |
| Failed to get ip address | IP 못 가져옴 | (Wi-Fi 방식일 때만) 그냥 **`한 번에 연결`** 을 쓰세요. 시리얼은 기본값으로. |

### 🟩 ② 서버(Server) 줄이 빨간불
| 메시지 | 뜻 | 해결법 |
|---|---|---|
| ADB not connected | ADB가 먼저 안 됨 | ① ADB부터. `한 번에 연결` 다시 누르기. |
| Failed to get arch | 기기 종류 확인 실패 | 블루스택 재시작 후 재시도. |
| Cannot find frida server | 내장 도구 파일 없음 | **백신이 지웠을 가능성 큼** → 2-5 예외등록 후 **재설치**. |
| Failed to deploy frida server | 도구를 에뮬에 못 넣음 | 에뮬 저장공간 확보, 블루스택 재시작 후 재시도. |
| Frida permissions denied | 권한 거부됨 | **2-3 루트(Root) 켜기** 안 했음. 켜고 **블루스택 재시작**. |
| Frida server crashed | 도구가 꺼짐 | 블루스택 재시작 → 처음부터 다시. |
| Failed to start frida server | 도구 실행 실패 | 위 루트 확인 + 블루스택 재시작. |

### 🟪 ③ 프리다(Frida) 줄이 빨간불
| 메시지 | 뜻 | 해결법 |
|---|---|---|
| ADB not connected | ADB가 먼저 안 됨 | `한 번에 연결` 다시. |
| Failed to connect to frida server | 도구에 접속 실패 | 서버가 막 켜져서 그럴 수 있음. **5초 기다렸다 `Connect Frida` 다시**. (`한 번에 연결`은 자동 재시도함) |
| Frida server crashed | 도구가 도중에 꺼짐 | 블루스택 재시작 → 처음부터. |

### 🟧 ④ 세션(Session) 줄이 빨간불
| 메시지 | 뜻 | 해결법 |
|---|---|---|
| Frida not connected | 프리다 먼저 안 됨 | ③ 프리다 초록불 만든 뒤에 누르세요. |
| Failed to get cookie | 쿠키 못 가져옴 | **게임을 로비까지 실행**한 상태인지 확인 후 다시. |
| Failed to start agent | 기능 붙이기 실패 | `Get Cookie` 먼저 → 그 다음 `Start Agent`. 안 되면 게임 재시작. |
| Module not found | 게임 내부를 못 찾음 | 게임/프로그램 **버전이 안 맞을 수 있음**. 둘 다 최신으로 업데이트. |
| Session disposed | 게임 연결이 끊김 | 게임이 꺼졌거나 튕김. 게임 재실행 후 처음부터. |

## 😱 아무것도 모르겠으면 이것부터 (만능 리셋)

**무슨 오류든 90%는 이 순서로 해결됩니다. 위에서부터 차례로 하세요.**

1. 🥛 **밀크초코 게임을 완전히 종료**
2. 🟦 **블루스택을 완전히 종료** (작업표시줄/트레이에서도 끄기)
3. ⚙️ **はぐるま 프로그램도 종료**
4. 🟦 **블루스택 다시 켜기**
5. 🔍 블루스택 설정 → 고급에서 **ADB 켜짐 / 루트 켜짐** 다시 확인 (2-2, 2-3)
6. 🥛 **밀크초코 실행 → 로비까지 들어가기**
7. ⚙️ **はぐるま 실행 → 로그인 → Initialize → `한 번에 연결`**
8. 그래도 안 되면:
   - 컴퓨터 **재부팅** 한 번
   - **백신 예외 등록(2-5)** 다시 확인 + 프로그램 **재설치**
   - 프로그램과 게임을 **최신 버전**으로 업데이트

## 7. 자주 묻는 질문

**Q. 방화벽 내려야 하나요?**
A. ❌ 아니요. 프리다 연결은 전부 내 PC 안(localhost)에서만 일어나서 방화벽과 무관합니다.
   진짜 문제는 보통 **백신(2-5)** 입니다. 방화벽 허용 창은 "모바일 컨트롤러" 기능을 쓸 때만 한 번 뜨고, 그땐 그냥 **[허용]** 누르면 됩니다.

**Q. `한 번에 연결`이랑 아래 버튼들 차이?**
A. `한 번에 연결`은 아래 버튼들을 **자동으로 순서대로** 눌러주는 거예요. 평소엔 이것만 쓰면 됩니다.

**Q. frida-server를 매번 다운로드해야 하나요?**
A. ❌ 아니요. 프로그램에 들어 있고 자동 설치됩니다. Download/Upload 버튼은 고급용이라 건드릴 필요 없어요.

**Q. 한 번 연결하면 계속 되나요?**
A. 게임이나 블루스택을 끄면 풀립니다. 다시 켜면 **`한 번에 연결`** 한 번 더 누르세요.

**Q. 자꾸 프로그램이 사라져요.**
A. 백신이 지우는 겁니다. **2-5 백신 예외 등록**을 꼭 하세요.
